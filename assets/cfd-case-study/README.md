# CFD partnership portal case study

The public page is `page12.html`. Its stylesheet, navigation/back-to-top script, and opt-in visual editor live in this directory. Original screenshots remain under `assets/images/` and are referenced directly; their pixels are unchanged.

Append `?edit=1` to open the visual editor. Text edits, section visibility, undo/redo and drafts stay in the browser. Download page exports a clean self-contained HTML file; Save editable copy includes the editing tools. Neither action publishes changes.

Content is based on the previous `page12.html`: six-week inception, research planning and interviews, journey mapping, stakeholder prioritisation, early flows, and design-system collaboration. Interface numbers are sample data. Qualitative feedback is distinguished from measured post-launch results; no new success statistics or participant quotes were invented.

The header, typography, colours, footer and back-to-top control follow the SSP case study and homepage. Research images are inline; wide diagrams can be scrolled horizontally on small screens. There are no image viewers or collapsed artefact sections.

This custom page is maintained directly in HTML/CSS/JS. The Mobirise project was not updated; exporting that project again can overwrite this page.

Validation: JavaScript syntax, local asset and chapter targets, unique IDs, image aspect ratios, footer text and CSS rule balance. Automated browser visual QA was unavailable in the authoring environment; review the private rendered Site before merging.
